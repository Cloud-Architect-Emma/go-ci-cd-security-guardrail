# Go CI/CD Security Guardrail

This project demonstrates how to build a secure CI/CD pipeline using:

- Go-based deterministic security enforcement
- AI-assisted vulnerability detection
- Policy-as-code validation
- Real-time incident response

## Architecture

GitHub Actions → AI Scan → Policy Engine → Go Security Gate → Deployment

## Features

- Detects hardcoded secrets
- Enforces deterministic security rules
- Blocks unsafe builds
- Lightweight Go CLI tool

## Use Case

Designed for DevSecOps pipelines requiring reliable enforcement beyond AI-based scanning.
